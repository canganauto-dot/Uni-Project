# Bundled font provenance

These upstream font files are unmodified and embedded for offline desktop rendering. Keep the accompanying copyright notices and complete SIL Open Font License 1.1 texts when distributing the application.

| File | Upstream source | License |
| --- | --- | --- |
| `Manrope.ttf` | [Google Fonts Manrope variable font](https://github.com/google/fonts/tree/main/ofl/manrope), upstream filename `Manrope[wght].ttf` | `Manrope-OFL.txt`; copyright The Manrope Project Authors |
| `IBMPlexSansArabic-Regular.ttf` | [Google Fonts IBM Plex Sans Arabic](https://github.com/google/fonts/tree/main/ofl/ibmplexsansarabic) | `IBM-Plex-Sans-Arabic-OFL.txt`; copyright IBM Corp., reserved name Plex |
| `IBMPlexSansArabic-SemiBold.ttf` | Same IBM Plex Sans Arabic distribution | Same license |

The font binaries are versioned in Git, so a build does not fetch a changing remote font. The Manrope filename was simplified locally; its internal font name and binary were not modified. The prototype uses explicit weight-axis settings for this variable font. The fonts are not sold on their own.
