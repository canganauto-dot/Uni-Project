# Embedded fonts

Unmodified static TrueType fonts from the Noto project, pinned to commit
`ffebf8c1ee449e544955a7e813c54f9b73848eac` of
https://github.com/notofonts/noto-fonts .

Files: NotoSans-Regular, NotoSans-Bold, NotoSansMono-Regular and NotoNaskhArabic-Regular.
Original paths are `hinted/ttf/<family>/<filename>.ttf`.
All are licensed under SIL Open Font License 1.1; see the accompanying LICENSE.
They are bundled so offline exports do not depend on installed system fonts.
PDFBox embeds subsets of the fonts used by each document. No font has been renamed or modified.
